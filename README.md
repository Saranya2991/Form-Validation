# Form-Validation
# 📝 Simple Registration Form (HTML, CSS, JavaScript)

This project is a **basic registration form** built using **HTML tables** for layout and **JavaScript** for real-time form validation.  
It checks that the **Name**, **Email**, and **Password** fields are filled correctly before allowing submission.

---

🚀 Features

- ✅ Real-time validation (as the user types)
- 🚫 Submit button disabled until all fields are valid
- ⚡ Uses `preventDefault()` to stop page reload on form submission
- 🧱 Simple table-based form layout
- 💡 Easy to understand and beginner-friendly
